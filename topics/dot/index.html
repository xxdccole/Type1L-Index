State DOT acceptance

23 resources · Last updated November 8, 2026

Key points

Type IL collection. These points describe portland-limestone (Type IL) mixtures and exposures already indexed. They are not general rules for every cement or concrete.

  • Broad acceptance: PCA reports acceptance by 50 states by Feb 2024.
  • Limestone limits: Nov 2024 survey: only Idaho capped limestone below 15% (12.5%).
  • IL(HE) emerging: Ohio has a spec section, NYSDOT approved one product, others trialing as Type III replacement.
  • Approved lists: TxDOT Item 421, Caltrans authorized list (M 240), MnDOT certified sources.
  • Tighter caps returning: INDOT RSP 901-M-069 (effective Dec 2025) limits limestone in Type IL to 10% by mass of the finished cement, including production tolerance.
  • NYSDOT's Sept 2026 specs accept Type IL under AASHTO M 240 but require the portland cement in any blend to be Type II or II(MH) (R69); INDOT's 2026 book lists Type IL under M 240 (R70).
  • SCDOT publishes a dedicated Type IL authorized supplier list (QPL 86, R102).
  • Oklahoma DOT lists Type IL(10) sources on its cement QPL (Ash Grove Foreman AR & Chanute KS; Amrize/Holcim Ada OK & Midlothian TX) (R131).
  • West Virginia DOH (R139, eff. 2026-09-15): certified mill list includes a dedicated ASTM C595 Type 1L section (material code 701.003.001) with Amrize, Quikrete, Buzzi, Fairborn, Heidelberg, Kosmos, Roanoke and St. Mary's sources.
